# Browser demonstration proof

[Open the final proof PDF](Interactive-Memory-Allocation-Simulator-Browser-Proof.pdf).

The 15 A4 landscape pages mainly show screenshots from the simulator: allocation strategies, partition modes, process lifecycle, fragmentation, compaction, comparisons, and supporting controls. The final page summarizes all 40 built-in scenario combinations.

## Reproduce the main example

1. Open Simulation studio and start the guided demo.
2. Advance through the releases: total free memory is 550 MB, but the largest hole is only 250 MB.
3. Observe the failed 400 MB request.
4. Compact and retry: the request succeeds, leaving 150 MB free.
5. Run the Algorithm Comparison scenario to compare the same workload under all four strategies.

The raw screenshot collection, duplicate archive, intermediate data files, and exported sample report were removed during cleanup. The final PDF retains the selected screenshot evidence.
